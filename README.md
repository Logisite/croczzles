# croczzles

A shelf of things built once and reused.

Each subdirectory is one self-contained thing: a script, a skill, a small set
of files that belong together. Nothing here imports from its neighbours, and
nothing assumes a particular project. Take the folder, read its README, use
it.

| folder | what it is |
|---|---|
| `board/` | a message board made of plain files, with a notifier that wakes agents |
